# Review: edit layer and edit tools (rewisp)

> **Historical review status 2026-10-25 (note from 2026-11-23):** paths and class names refer to the single-module layout of that time (`src/main/java/...`, tools under `tools/`). Since 2026-11-18 the project is split into `src_rewisp` (backend) and `src_mcp` (MCP tools); mentioned classes like `RewriteTypeUtils`, `TypeInfo` no longer exist. Current state: [../ARCHITEKTUR.md](../ARCHITEKTUR.md) (sections "Package overview" and "Module boundary").

Scope: `edit/*`, `tools/BaseEditTool`, `TransactionTools`, `EditLineTool`, `Add*Tool`, `EditAnnotationTool`, `MoveClassTool`, `RemoveAnnotationTool`, `RemoveMemberTool`, `RenameSymbolTool`, `ReplaceMethodBodyTool`, `RewriteSignatureTool`, `RewriteTypeUtils`, `SourceCodeUtils`, `ToolCallGuard`.
Known bugs #11, #14, #15, #16 are not reported again. Where a finding adds to them, it says so in the description.

Line numbers were verified against the read file state. Dead-code statements were checked per grep over `src/main` and `src/test`.
