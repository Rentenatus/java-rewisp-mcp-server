## Hypotheses (not evidenced, please verify)

- Most edit tools only parse the target file (`Set.of(relativeFile)`). Types from other files/packages are not attributed there; `maybeAddImport(fqn)` (default `onlyIfReferenced=true`) may then not add the import (AddField/AddMethod/ReplaceMethodBody, with `imports` from the Spoon analysis). Check per test with a type from another package.
